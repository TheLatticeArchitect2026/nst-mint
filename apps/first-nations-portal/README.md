# NST Lattice First Nations Portal

Status: scaffold only.

Purpose: future First Nations participation, legal language, governance, and revenue-sharing information surface.

This is not a deployment authorization.

This surface must not be finalized without specialized Treaty-law review.

A First Nations lawyer specializing in Treaty law should be treated as a critical contributor for:

- Treaty-law language;
- governance framing;
- revenue language;
- rights language;
- representation language;
- consent language;
- community onboarding language;
- legal disclaimers;
- possible multisig or key-holder role design.

This surface must not collect private keys, seed phrases, wallet secrets, deployer keys, API keys, or recovery phrases.

This scaffold creates no frontend runtime code.
