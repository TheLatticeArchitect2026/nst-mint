# NST Lattice Applications

Status: scaffold only.

This directory defines future NST Lattice application surfaces.

This is not a deployment authorization.

No production deployment is authorized by this scaffold.

No secrets, private keys, seed phrases, deployer keys, API keys, wallet secrets, or recovery phrases belong in this directory.

Planned application surfaces:

- `public-site` — public landing page and education surface.
- `corporate-site` — corporate and enterprise participation surface.
- `base-sepolia-demo` — controlled testnet demo surface only.
- `first-nations-portal` — First Nations legal/governance participation surface, pending specialized Treaty-law review.
- `admin-console` — future protected governance/operator console, not built in this scaffold.

No app runtime code is created by this scaffold.
