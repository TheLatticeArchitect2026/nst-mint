# NST Lattice Public Config Package

Status: scaffold only.

Purpose: future public, non-secret configuration package.

This is not a deployment authorization.

Allowed future config values may include:

- public chain IDs;
- public RPC references only where safe;
- public contract addresses after approval;
- public feature flags;
- public environment labels;
- public documentation URLs.

Disallowed values:

- private keys;
- deployer keys;
- seed phrases;
- wallet secrets;
- API keys;
- recovery phrases;
- private RPC credentials;
- unreleased production addresses;
- placeholder production addresses presented as final.

No config runtime file is created by this scaffold.
