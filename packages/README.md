# NST Lattice Packages

Status: scaffold only.

This directory defines future shared packages for NST Lattice applications and transaction rail work.

This is not a deployment authorization.

No production package is created by this scaffold.

No private keys, seed phrases, wallet secrets, deployer keys, API keys, or recovery phrases belong in this directory.

Planned package areas:

- `transaction-rail` — future end-to-end value movement rail package.
- `protocol-clients` — future read-only contract client package.
- `governance-gates` — future shared readiness and approval gate logic.
- `ui` — future shared UI components.
- `config` — future public, non-secret configuration only.
